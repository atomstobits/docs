Welcome to the PAW documentation. PAW (Physical Agent Worker) is a zero-dependency CLI that gives your AI agent a real, animated presence in a Chromium browser — every action is visible on-screen, logged locally, and interruptible by you at any moment. It is built for developers and teams who want AI browser automation they can actually watch and trust.

## Get Started in Three Steps

<Steps>
  <Step title="Install PAW">
    ```bash
    npm i -g paw-core
    ```
    Requires Node.js 22 or later. Zero runtime dependencies — no browser downloads.
  </Step>

  <Step title="Launch a browser session">
    ```bash
    paw start brave --url https://example.com
    ```
    PAW connects to your existing Brave, Chrome, or Edge installation via the Chrome DevTools Protocol and renders an animated cursor in the live browser window.
  </Step>

  <Step title="Start automating">
    ```bash
    paw snapshot
    paw click 1
    ```
    `paw snapshot` lists every interactive element on the page with a numeric index. `paw click 1` walks the cursor to that element along a Bézier curve and fires a real click — at human pace, on-screen, fully logged to `~/.pawprint`.
  </Step>
</Steps>
